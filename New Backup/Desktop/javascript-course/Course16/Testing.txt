Mock:
Lets us replace the method with fake version to anything we want.Below is the example of mock.
We are testing addToCart function by adding one product to cart and make sure it equal to 1 but the problem is on carts.js we have stored the carts intolocal storage so there might be the data inside it , so we cant get the expeted results and  if no data inside the localStorage carts then we are adding default 2 values to cart. so we cannot go and update the script in order to fix it for our testing we have created the mock.
Mock can be created using spyOn
spyOn(localStorage, 'getItem').and.callFake(() => {
      return JSON.stringify([]);
    }); - What we do here is spyOn will take 2 parameter, object and its method, here localStorage is object and getItem is method and mthod shoulbe be inside '' and spyOn(localStorage, 'getItem') will become an object and it has property called and and spyOn(localStorage, 'getItem').and. will become object and it has method callFake where we write what the fake output should look like else the return. for our case we need this to be in empty array, so if the cart is empty array we can do this expect(carts.length).toEqual(1); ie carts.length === 1 then we can make the test case pass. so in below example we are returning the carts as [] abd the localstorage op will be string so we convert to string . so here i have called this function loadFromStorage(); go to carts.js file and look for the steps. The reason we converted to fn is after we modified the carts to empty array we need to load it back to orginal carts.js so  saying now ist empty so the rest of the code in carts.js think its an empty array and perform its action. now expect(carts.length).toEqual(1); will pass, then we add spyOn(localStorage, 'setItem'); line beacuse after addToCart fn run its store the data to localStorage but we dont want to add our testing data to carts so we have mocked it and we did not use .and.callFake(() as we no need to return annything and we have add expect(localStorage.setItem).toHaveBeenCalledTimes(1); this is to validate after each time data is added to cart the localStorage.setItem is the data is added that we validate with toHaveBeenCalledTimes(1);this will tell how many time this method is called after mocked ie spyOn(localStorage.setItem) this is method. to perform this we set mock for this spyOn(localStorage, 'setItem');Each test can have multiple expect, if all expect pass then only test will be passed



import {carts, addToCart, loadFromStorage} from '../../data/carts.js';


describe('test suite: add to cart', () => {
  it('adding one product to cart', () => {

    spyOn(localStorage, 'setItem');
    spyOn(localStorage, 'getItem').and.callFake(() => {
      return JSON.stringify([]);
    });

    loadFromStorage();

    addToCart('e43638ce-6aa0-4b85-b27f-e1d07eb678c6');
    expect(carts.length).toEqual(1);
    expect(localStorage.setItem).toHaveBeenCalledTimes(1);

  });
});
