To create a test suite or group multiple test case use describe.describe take 2 inputs one is test suite name and second one is ()=> {} fn where inisde it we will write all the test case related to the test suite. Test suite name we can give anything which make sense, here formatMoney i have given which is the function for that function we are creating multiple test case.

it is where we will write the test case, it will take 2 imputs one is name of the test case we can give some relevent name, then fn, where we write the test case.expect is used to check for the result. Here expect(formatMoney(1099)).toBe('$10.99'); we have used formatMoney function inside the expect so once that fn is run expect will have that value and that we are comparing with toBe value. toBe is the value we have gien to check whether we are getting expected result.We can have multiple expect inside the it

First we need to import
import {it, describe,expect } from 'vitest';
import { formatMoney } from './money';

describe('formatMoney', () => {

  it('check the data working for $1099', () => {
    expect(formatMoney(1099)).toBe('$10.99');
  });
  it('check the data working for $10 & $103', () => {
    expect(formatMoney(10)).toBe('$0.10');
    expect(formatMoney(103)).toBe('$1.03');
  });
});

Integration Testing Example:
import {it, describe,expect, vi } from 'vitest';
import { Products } from './Products';
import { render, screen } from '@testing-library/react';


describe('Product Component', () => {

  

  it('Checking whether its display the proper information on the page', () => {

    const product = {
    id: "e43638ce-6aa0-4b85-b27f-e1d07eb678c6",
    image: "images/products/athletic-cotton-socks-6-pairs.jpg",
    name: "Black and Gray Athletic Cotton Socks - 6 Pairs",
    rating: {
      stars: 4.5,
      count: 87
    },
    priceCents: 1090,
    keywords: ["socks", "sports", "apparel"]
  }

  const loadCart = vi.fn();
  
    render( <Products product={product} loadCart={loadCart} />);
    expect(screen.getByText('Black and Gray Athletic Cotton Socks - 6 Pairs')).toBeInTheDocument();
    expect(screen.getByText('$10.90')).toBeInTheDocument();
    expect(
      screen.getByTestId('product-image')
    ).toHaveAttribute('src', 'images/products/athletic-cotton-socks-6-pairs.jpg');

    expect(
      screen.getByTestId('product-rating-stars-image')
    ).toHaveAttribute('src', 'images/ratings/rating-45.png');

    expect(
      screen.getByText('87')
    ).toBeInTheDocument();
  });
});
