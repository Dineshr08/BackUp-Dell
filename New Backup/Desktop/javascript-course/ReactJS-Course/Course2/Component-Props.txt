Component:
A piece of website. Like we have chatbot application input and send we can consider as piece of website of chatbot application, then on each user input as each piece then each chatbot response we can consider as a piece.So creating aplication into piece we can make website easier which is core concept of react
When we create a component it should be as function and function name as pascalcase.
Eg below for chatbot input entering piece
function ChatInput() {
        return (
          <>
            <input 
              placeholder= "Send a message to Chatbot" 
              size="30" />
            <button>Send</button>
          </>
        );
      }
The design we do for that piece ie html element should be inisde the return statement, so we can call when we combine to make a complete application.
Using component we can create our own html instead of just regular html elements like button, input etc.Eg fn ChatInput() become an html element now  we can call it like <ChatInput/> here i am made selfclosing which means the ChatInput element donsent have any name so instead of <ChatInput></ChatInput> we can give like <ChatInput /> which is self closing

<!DOCTYPE html>
<html>
  <head>
    <title>React Basics</title>
  </head>
  <body>
    <div class="js-container"></div>

    <script src="https://unpkg.com/supersimpledev/react.js"></script>
    <script src="https://unpkg.com/supersimpledev/react-dom.js"></script>

    <script src="https://unpkg.com/supersimpledev/babel.js"></script>
    <script type="text/babel">

      function ChatInput() {
        return (
          <>
            <input 
              placeholder= "Send a message to Chatbot" 
              size="30" />
            <button>Send</button>
          </>
        );
      }

      function ChatMessage({message, sender}) {
        
        // const message=  props.message;
        // const sender = props.sender
        // const {message} = props;
        // const {sender} = props;

        return (
          <div>
            {sender === 'robot' && (<img src="robot.png" width="30"/>)}
            {message}
            {sender === 'user' && (<img src="user.png" width="30"/>)}
          </div>
        );
      }
    //Here we have grouped every piece as each piece is single html now
      function App() {
        return (
          <>
            <ChatInput />
            <ChatMessage 
              message="hello" 
              sender="user" 
            />
            <ChatMessage 
              message="Hello! How can I help you?" 
              sender="robot"
            /> 
            <ChatMessage 
              message="flipcoin" 
              sender="user" 
            />
            <ChatMessage 
              message="Sure! You got tails" 
              sender="robot"
            /> 
          </>
      );
      }
      const container = document.querySelector('.js-container');
      ReactDOM.createRoot(container).render(<App />);
    </script>
  </body>
</html>
