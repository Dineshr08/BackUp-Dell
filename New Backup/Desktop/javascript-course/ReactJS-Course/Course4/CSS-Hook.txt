useRef();
Automatically save the html element from the component
ref is the container with special react feature.
We should use this above the useEffect hook, By default this will store the null value and can save it variable
const chatMessagesRef = React.useRef(null);.
Then on the html element ie inside the compinent return wherw we can give like below
<div className="chat-messages-container" ref={chatMessagesRef}>
On div container we have added the prop called ref={chatMessagesRef} which is refering the above ref, so what will happend is when the component is created , it the html element will automatically stored inside the chatMessagesRef, then that we can use indie the useEffect hook to scrol automatically. because toi scroll automatically we need an html element, to capture that html element we use the useRef.So once the component is created we capture the html element, then taht element we can pass to useEffect, beacuse the use effect will run once the component is created, as the componet is created it will store the html of the component in the ref variable which we can use in useeffect.
Eg below:
 function ChatMessages({ chatMessages }) {
        const chatMessagesRef = React.useRef(null);

        React.useEffect(() => {
          const containerElem = chatMessagesRef.current;
          if (containerElem) {
            containerElem.scrollTop = containerElem.scrollHeight;
          }
        }, [chatMessages]);

        return (
          <div className="chat-messages-container" ref={chatMessagesRef}>
            {chatMessages.map((chatMessage) => {
              return (
                <ChatMessage
                  message={chatMessage.message}
                  sender={chatMessage.sender}
                  key={chatMessage.id}
                />
              );
            })}
          </div>
        );
      }
