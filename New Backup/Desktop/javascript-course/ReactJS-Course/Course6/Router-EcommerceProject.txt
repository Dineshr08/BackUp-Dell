Routing:
To create a multiple pages in react we use routing.
To use routing we need to install package called react-router
npm install react-router@7.8.0.
To use router we need to follow few steps. Need to surround App component with BrowserRouter like below
<StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>,
Then on App component page need to add below
Add Routes first which is were we will include all the available pages of the webiste.Each pages deetails need to mention inside the Route. It will take 2 props one is path and element. On element we need to add the component insise {} and on path we need to give path ie after end point the webpage url eg .com/checkout. if we dont have anything after .com like homepage we can mention either "/ or index both are same and we have handled selfclosing as well here". Add imports as well for the component
Eg:
 <Routes>
      <Route path="/" element={<HomePage />} />
      <Route path="checkout" element={<CheckoutPage />} />
    </Routes>
    </>

<Routes>  - This is compenent, this routes component tells all the pages that are in our webisite
To add a page to our webiste need to use component called Route
Route = page
