Install Node JS
To check the version 
node -v
We installed node js to run the javascript file.
Command:
node javascriptFile.js
To install external libary: node package manager
npm install externallibrary
Open a terminal from the project folder and install the library using above command , It will create a folder called node-module inside the folder path, where all the installed library will be located.
While installing if we get an error run below command.
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

Some packages will create a command for the command line.
Eg create-vite - It will create a command called create-vite, it will help us to create the new react project.


SetUp New React Project:
We know create-vite will help us in setup new react project, to do that need to perform 2 steps
1. npm install creat-vite
2. Run create-vite
Instead od doing both seperately we can run below command
npx create-vite 
Here x means execute , it will install and execute.
npx create-vite@6.5.0 here we are mentioning the version of the create-vite as well.
While running this command it will ask for the project name - Give project name our case it will be chatbot-project, then it will as for technology choose react and javascript by using arrow icon to navigate and click enter.

Once project is created we can see package.json - it will have list of package that needed for this react project, to install all just give
npm Install
Once installation is done, to start up the new project in webiste run below command
npm run dev
We will get http webiste url just launch that in browser.

Folder Structure:
node-module - It will contain all the installed packages
src - Source folder , all our codes ie css, javascrpt files. here javascript need to save as jsx.
public - store Files that are accessible to public. When  we deploy this application , the files here should be accessible through the url
Files inside the folders:
.gitignore - Hold the git related details
eslint.config.js - it will highlight the error in js. To identify the error need to install eslint extension in vs code.
index.html - Will have actual our webiste html code. in Script element we gave the the css and jsx file path
package.json - will have all the package that need to installed
package-lock.json - Holds all the installed package version related details , when we install or update the package those file will be auto updated.
vite.config - Its vite config file
Vite - Will help us in setup the project, It will help us in create a website and act as server for our website, because it will deploy and give as end point as well, and when we work on website it will update the changes innrealtime like liveserver.
We usually touch only index.html and files inside the src folder.
