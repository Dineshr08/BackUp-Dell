Browser->Request->Server(Middleware)->Response->Browser
When we send the req we will send from browser the it send to server, before we are getting back response if we need to perform something that is middleware.Usuallly middleware dosent need to send any response, its work is just ptrocees the if we give next it will go to next step. in express everything will run from top to down approch. We usually define middleware using use, on use we need to give next, usually use take ananymous fn ie call back it will take 3 arguments req, res and next using that next we will tell if middleware executed go to next , Eg if we kept middlewarwe1 inbetween /home and /contact and middleware 2 inbetween /about and notfound and if we perform any get req like /contact it only execute middleware 1 as middleware 2 wont execute as already we sent response back so it wont execute midddleware 2 , but if we keep both midd 1 and 2 before contact both will execute becuase we yet to send the response back to server, all middle will execute until we send response back.   { id: 4, userName: "Rajendran" },

  res.send(users);
});
app.get("/api/users/:id", (req, res) => {
  const userID = parseInt(req.params.id);

  if (isNaN(userID)) {
    return res
      .status(400)
      .send({ msg: "Bad Request, Please check the input user id" });
  }

  const user = users.find((user) => user.id === userID);
  if (user) {
    return res.send(user);
  }

  res.status(404).send({ msg: "User Not Found" });
});
