Sessions:

Below are the steps followed for sessions
Sessions - We are creating the session for the api 
First need to install the express-session
npm i express-session

Then on index.mjs file need to use session as middleware and above the router middleware so this session will applied to all the api in routers. if i create a session in one api and after that if i access other api it will applied to other api with same session id.
app.use(session({
  secret: "hello secret",
  saveUninitialized: false,
  resave: false,
  cookie: {
    maxAge: 3600000
  }
})) - Session will take many arguments , theres are some imp arguments that we passed in object. Secret - just like cookie we give secret value based on that it will encrypt the sessio id. saveUninitialized as false , so eg it wont save a session on the server until we add something, eg if i just use flipcart page on broswer it wont save session on server, it will just create one , to save that we need to add something , add means login or add some product to cart etc.resave: false - if we have session and if we dont perform any add or update , it wont rewrite the session, eg if we are at 40 min of 60 min session , until add or update it will be in 40  min.Cookie - Using cookie only we will send the session from server to client and we are mention the expiry time here.
