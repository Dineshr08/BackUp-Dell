Object are referance:
const obj1 = {
  name: 'Dinesh',
  age: 30
}
When we create a object it stored in a computer memory , basically obj1 dosent hold the value ie {
  name: 'Dinesh',
  age: 30
}, what it will dose is obj1 will hold the reference or address where the value is stored

const obj2 = obj1 so here obj1 value is not copied to obj2 , its just share the same address. both obj1 and 2 point to same address or referances. its a copy by referances
if we do console.log(obj1 === obj2) it will return  true as we are comparing both address and both are same so return true
 const obj3 = {
  name: 'Dinesh',
  age: 30
} it store in some different address in computer memory if console.log(obj1 === obj3) it return false as address will be different and here its compare address not value
if we do obj1.name = 'Thilaga' it will update as its const as we are updating the value not the referance
